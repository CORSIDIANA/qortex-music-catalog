# Engineering scope

This is an independent Qortex assignment. Read docs/SPEC.md before edits.
Only modify this repository. Internal source repositories are read-only and must not be copied wholesale.
Use small Django/DRF/Vue modules, PostgreSQL-backed tests and actual command evidence.
Never report PASS from inspection alone. Preserve another contributor's work.
Workflow: specification → bounded change → tests → independent critique → regression fix → fresh verification.
The public repository must contain no internal source paths, credentials, customer data or proprietary implementation.
